Macronaut → Auto clicker with image recognition

An auto clicker that clicks a button wherever it is

An ordinary auto clicker clicks a position. The moment the button is somewhere else (the window opened further left, the list scrolled, the screen is a different size) it clicks empty space, and it keeps doing that until you notice. Macronaut can find the button by what it looks like, wait for it to appear, and click it where it actually is.

In one sentence. You show it a picture of the button; it watches the screen until that picture appears, then clicks it.

How to set it up

  1. Open Advanced and add a Detect step, set to look for an image.
  2. Press Capture… and drag a box around the button on screen. A small, distinctive crop works better than a large one.
  3. Press Test match to check it finds the button now.
  4. Tick Click the image when it appears. Click on the preview to choose where on the image the click lands, if not the centre.
  5. Set Give up after to a number of seconds, or leave it waiting for as long as it takes.

Press Play. The step waits, finds the button, glides the pointer to it and clicks.

Making it reliable

  • Set a search area. Limiting the search to part of the screen is faster, and it stops the step finding the same icon somewhere you did not mean.
  • Adjust the match confidence. It starts at 0.8. If a script stops matching on another screen, lower it a little; if it matches the wrong thing, raise it.
  • Display scaling is handled for the common cases. A button captured at 100% scaling is also searched for at the usual Windows scaling steps, so moving to a laptop at 150% does not mean recapturing everything.
  • Plain-coloured and cut-out images work. A flat colour block and a PNG with a transparent background are both matched properly, by the parts you can see.

What it cannot do

Image matching compares pixels. It is not a model that understands what a button is, and it fails in predictable ways:

  • The button looks different. A dark theme, a hover highlight, or a disabled grey version are different pictures. Capture the state you want it to click.
  • The button is not visible. A covered or minimised window shows nothing to match.
  • Searching the whole screen takes a moment. When the image is not there, a full-screen search can take a second or two. A search area makes it much quicker.

More than images

The same Detect step can wait for text, read with the OCR built into Windows, so you can wait for “Download complete” and click it. It can also wait for a single pixel to change colour. Put any of them inside a Loop, or branch with If/Else on whether it was found, and a replay that used to break on a slow day becomes a script that waits for the screen it needs.

If all you want is clicking on a timer, Macronaut opens on a plain auto clicker that needs none of this.
