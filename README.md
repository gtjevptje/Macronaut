### ⬇ [Download Macronaut for Windows](https://github.com/gtjevptje/macronaut-releases/releases/latest/download/Macronaut.exe)

One file, no installer. Run it. It updates itself.

Windows autoclicker and input automation — a visual flow builder, image and text
detection, and driver-level input for games that ignore ordinary clicks.

**Requires** Windows 10 or 11 (64-bit).

**First run:** Macronaut isn't code-signed yet, so Windows SmartScreen shows
"Windows protected your PC". Click **More info → Run anyway**. Every release is
published here with its SHA-256 in [update.json](https://github.com/gtjevptje/macronaut-releases/releases/latest/download/update.json) if you want to verify the file.
