Macronaut → Auto key presser

A free auto key presser for Windows

Pressing the same key a few hundred times is the kind of job a computer should do for you: arrowing down a long list, skipping through a form, keeping a game character walking. Macronaut presses keys for you, on a count or on a timer, and can hold one down while it does something else.

The quickest start. Macronaut arrives with a script called Press a key 50 times already in its library. Open it, double-click the key step to pick your key and the count, press Play.

What it can do with a key

  • Tap a key, as many times as you like in one step.
  • Hold a key for a set time, then let go.
  • Hold down a key and leave it down, so later steps can click or type while it is held, and release it when you are done. That is how you keep W held to run forward while clicking.
  • Combinations like Ctrl+C or Shift+Tab, pressed in the right order with the modifier first.
  • Type a whole block of text, at a speed you choose, for the reply or address you send twenty times a day.

A key held down when a script finishes, or when you press Stop, is released automatically. A stuck key is the worst thing an auto key presser can leave behind, so that path is built in rather than left to the script.

Press a key every few seconds

Repeating a key on a schedule is three steps on the canvas:

  1. Add a Loop, set to repeat forever or a number of times.
  2. Inside it, add a Key step with your key.
  3. After it, add a Wait step with the gap you want, from a few milliseconds to hours.

Press F8 to start and stop it, or Esc to stop anything at any time. You can also give each saved script its own key, so one key starts your key presser and another starts something else.

Keys in games

Plenty of games ignore keys sent the ordinary way, which is why a lot of key pressers work in Notepad and do nothing in the game. Macronaut has three input modes, chosen in Settings:

  • Standard, which works in ordinary windows.
  • SendInput scancodes, which press real key positions rather than characters.
  • Interception, a kernel driver that looks like a real keyboard to the game. You install the driver separately.

If one does not work in your game, try the next. And read the game’s rules first: many online games ban automation, and can ban the account that uses it.

Clicking too

The window Macronaut opens on is a plain auto clicker: interval, button, repeat, Start. Keys and clicks live in the same script, so a key presser can click, and a clicker can press keys. It can also wait for something to appear on screen before it presses anything.
